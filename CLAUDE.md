# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Что это

Персональная страница-визитка Форреста Гампа (вымышленный персонаж). Статический многостраничный сайт: HTML + один `style.css` + крошечный `theme.js`, без сборки, тестов, линтера и пакетного менеджера. Чтобы посмотреть результат, достаточно открыть `index.html` в браузере.

Профиль владельца — `profile.md`. Прочитай его, чтобы понимать, для кого и зачем сайт.

## Архитектура

- Страницы: `index.html` (hero + навигация по разделам + цитата), `about.html`, `work.html`, `facts.html`, `contacts.html`. Верхнее меню (`<nav class="nav">`) скопировано в каждую страницу вручную: при добавлении страницы правь меню во всех файлах и ставь `aria-current="page"` на текущем пункте.
- `style.css` — все стили. Цвета — CSS-переменные в `:root` (светлая тема) и `:root[data-theme="dark"]` (тёмная).
- `theme.js` — переключатель темы; выбор хранится в `localStorage`. Стартовая тема ставится маленьким inline-скриптом в `<head>` каждой страницы (по `prefers-color-scheme`), чтобы не было мигания.
- Контакты в `contacts.html` пока плейсхолдеры (`forrest@example.com`, `@forrest_gump` и т.п.), замени на реальные.
- `profile.md` — главный источник фактов для текста. Остальные `.md` в корне (`про-меня.md`, `проекты.md`, `факты.md`) — черновики-заготовки контента по тем же темам; страница собирается из них вручную, автоматической связи нет. При изменении фактов держи файлы согласованными.
- `images/` — картинки. Все взяты из Openverse под CC-BY / CC-BY-SA, источники и авторы записаны в `images/CREDITS.md`. При добавлении или замене картинки обновляй CREDITS.md и указывай атрибуцию.
- `__CLAUDE.md` — прежний файл с правилами проекта (стиль и дизайн). Его правила перенесены ниже; если правишь правила, правь этот файл, а `__CLAUDE.md` не считай актуальным.

## Правила проекта

**Стек:** простой HTML, без фреймворков и сборки. Стили и скрипты минимальные (JS только для переключателя темы). Не раздувать проект.

**Тон текста:** на «ты», сдержанно, но с юмором. Текст от первого лица в голосе Форреста: простодушный, честный, с мамиными поговорками.

**Дизайн:** мягкие пастельные сочетания, никаких кричащих цветов, не шаблонный вид «как у всех», не скучно. Стоковых фото избегать, лучше свои фото или иллюстрации. Мрачные и чёрные цвета не использовать. Тёмная тема допустима только мягкая: тёплый сливово-синий фон и пастельные акценты, без чёрного.

## Известное расхождение

Общий вид (Georgia, терракотовый акцент, карточки на кремовом фоне) всё ещё довольно типовой. Hero и финальный блок теперь используют мягкий сливовый градиент вместо почти чёрного.
