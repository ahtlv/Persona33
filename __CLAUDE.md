# Persona

Профиль владельца проекта лежит в profile.md, прочитай его, чтобы понимать, для кого и зачем этот проект.

## Цель
Персональная страница владельца проекта.

## Стек
- Простой HTML (index.html), без фреймворков и без сборки.
- Стили и скрипты минимальные, лучше без них, если без них можно обойтись.
- Картинки лежат в images/.

## Тон текста
- Обращение на «ты».
- Сдержанно, но с юмором.

## Дизайн
- Мягкие, красивые цветовые сочетания, пастельные тона.
- Не использовать кричащие цвета.
- Не использовать шаблонный вид «как у всех»: сайт должен отличаться.
- Стоковых фото избегать, лучше свои фото или иллюстрации.

## Чего не делать
- Не использовать тёмные, мрачные и чёрные цвета.
- Не делать скучно.
- Не раздувать проект и не тащить фреймворки.
